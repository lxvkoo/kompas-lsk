# Совместимость: что и на чём проверено

## КОМПАС-3D v22.0.0 (Windows, x64)

Доступ к API: **COM** — `KOMPAS.Application.7` + `kAPI7.tlb` через `comtypes`
(в v22 нет `ksapi.py` и `ksAPICLink.dll`).

`lsk_probe.exe` → `probe_report.txt`:

```

Каталог Bin: C:\Program Files\ASCON\KOMPAS-3D v22\Bin

версия КОМПАС-3D: 22.0.0
способ доступа к API: COM KOMPAS.Application.7
ЛСК через IAuxiliaryGeomContainer: да
«Показывать надпись»: да
коллекция 3D-точек: да
нормаль грани: да
удаление объектов: НЕТ          <- в COM-API удаления нет, отмена через Ctrl+Z

Активный документ: Деталь
--- возможности на этом документе ---
  коллекция ЛСК: да
  3D-точек в модели: 1
    · Точка:1: (0.000, 0.000, 20.000) мм
  окно документа: 2560x1255 px
  проекция первой точки в пиксель: (1254, 568)
  пиксель внутри окна: да
  масштаб вида: 0.1820 мм/пиксель
```

`lsk_placer.exe` → «Самотест» (`selftest_report.txt`): все проверки `[ok]`,
создание тройки с координатами `(0,0,0)` / `(0,10,0)` / `(10,0,0)` мм,
удаление пропущено (`[skip]`) — там только отмена командой КОМПАСа.

## КОМПАС-3D v25.0.5 (Windows, x64)

Доступ к API: **ksapi.py** (C-обёртка над `ksAPICLink.dll`), все возможности «да»,
включая удаление объектов из API.

Сквозной тест `tools/check_e2e.py`: привязка по пикселям (0 px), распознавание
всех шести осей протяжкой, координаты тройки, отмена одним `Ctrl+Z`.

COM-путь на v25 тоже проверен принудительно (`set LSK_BACKEND=com`): точки,
привязка, жест, создание тройки, отмена, панель и оба exe.
