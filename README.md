# ЛСК → КОМПАС

Утилита для быстрой расстановки локальных систем координат (ЛСК) в деталях
КОМПАС-3D. Один клик по проставленной точке модели — три ЛСК: базовая,
векторная (`_V`, отступ по нормали) и поворота (`_R`, отступ в плоскости грани).

Работает через официальную Python-обёртку API КОМПАС-3D (`ksapi.py` из каталога
`Bin` установленного КОМПАСа) — без COM, без внешних зависимостей.

## Как это выглядит в работе

1. В детали инструментом «Точка» / «Точка в центре» проставляются точки — там,
   где должны стоять ЛСК.
2. Запускается панель (`python main.py`), выбирается имя (например `ЛСК_Т03`).
3. Включается режим установки (кнопка или `Ctrl+Alt+L`).
4. Клик по точке на модели → в модели появляются `ЛСК_Т03`, `ЛСК_Т03_V`,
   `ЛСК_Т03_R` с включённой надписью. Режим остаётся включённым: выбираешь другое
   имя и кликаешь дальше.

Направление берётся из геометрии: ось Y базовой ЛСК = нормаль грани в точке,
ось X — проекция глобальной X на плоскость грани, Z = X×Y. Поэтому ЛСК корректно
ставятся на любую плоскость (сверху, сбоку, сзади). Кнопками в панели можно
выбрать «наружу/внутрь» для `_V` и ось для `_R` (`+X`, `-X`, `+Z`, `-Z`) —
выбор запоминается отдельно для каждого имени.

## Требования

* КОМПАС-3D **v22 и новее**, 64-бит, запущенный;
* Python 64-бит той же разрядности, что КОМПАС (проверено на 3.14);
* в каталоге `Bin` установленного КОМПАСа должны быть `ksapi.py`, `constants.py`,
  `constants3d.py` (есть в v25; наличие в v22 проверяется скриптом `probe_env.py`);
* сторонних библиотек не требуется — только стандартная поставка Python (Tkinter).

## Запуск

```bash
python probe_env.py    # диагностика: что доступно в твоей версии КОМПАСа
python selftest.py     # автотест: создаёт временную деталь, ставит/удаляет ЛСК
python main.py         # панель управления
```

`selftest.py` и `probe_env.py` не трогают твои модели: первый работает во
временном документе и закрывает его без сохранения.

## Как это устроено

```
main.py            точка входа
lsk/kompas.py      поиск установленного КОМПАСа, импорт ksapi, проверка возможностей API
lsk/model.py       активная деталь: коллекция ЛСК, точки, создание тройки, удаление
lsk/picking.py     клик -> точка на модели -> ближайшая 3D-точка -> нормаль грани
lsk/geometry.py    векторы, матрицы ЛСК (16 чисел), привязка к лучу
lsk/session.py     режим установки, перехват кликов, сценарий установки
lsk/ui.py          панель Tkinter (имена, направления, отступы, журнал)
lsk/config.py      настройки в %APPDATA%\lsk_placer\config.json
lsk/hotkey.py      глобальная горячая клавиша (RegisterHotKey)
```

Технические детали API (матрицы, единицы, найденные интерфейсы) — в
[docs/API_NOTES.md](docs/API_NOTES.md).

## Ограничения и планы

* Проверено на КОМПАС v25. Для v22 нужно прогнать `probe_env.py` и, если какие-то
  возможности называются иначе, включить запасные пути (они уже заложены:
  ЛСК через `IAuxiliaryGeomContainer` или `AddObject`, защита `hasattr`).
* Если точка не лежит на грани (например, центр отверстия в «пустоте»), направление
  берётся по ближайшей грани под курсором и в журнал пишется предупреждение.
  В планах — брать ось из окружности/цилиндра, к которым относится точка.
* Горячая клавиша пока задаётся в `config.json` (`"hotkey": "Ctrl+Alt+L"`).
* Сборка exe (PyInstaller) — после отладки в `.py`; учтите разрядность Python.
* Дубли имён не переименовываются: показывается предупреждение и запрос подтверждения.
