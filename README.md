# ЛСК → КОМПАС

Утилита для быстрой расстановки локальных систем координат (ЛСК) в деталях
КОМПАС-3D. Работает через официальную Python-обёртку API (`ksapi.py` из каталога
`Bin` установленного КОМПАСа) — без COM, без сторонних библиотек.

## Жест

1. В детали проставляются точки («Точка», «Точка в центре») — там, где нужны ЛСК.
2. В панели выбирается имя, например `ЛСК_Т03`.
3. Курсор наводится на точку.
4. **Зажимается `Ctrl+1`** — рядом с точкой появляется стрелка-подсказка
   (какая ось сейчас выберется для `_V`).
5. Мышь тянется в нужную сторону (любая из 6: ±X, ±Y, ±Z) — стрелка поворачивается
   на выбранную ось, подпись показывает её имя.
6. Клавиша отпускается — появляются три ЛСК:

| ЛСК | что это |
|---|---|
| `ЛСК_Т03` | базовая, ровно в точке |
| `ЛСК_Т03_V` | сдвинута на 10 мм в сторону протяжки |
| `ЛСК_Т03_R` | сдвинута на 10 мм по первой перпендикулярной оси (+X, +Y или +Z) |

Ориентация у всех трёх — **как у детали, без проворота** (оси ±X, ±Y, ±Z
совпадают с глобальными), меняются только координаты вставки.

Если потянуть совсем чуть-чуть (меньше 12 пикселей) — направление берётся то же,
что в прошлый раз для этого имени. Направление запоминается.

**Ошибся — просто `Ctrl+Z` в КОМПАСе**: создание тройки идёт одним шагом отмены,
поэтому убираются сразу все три ЛСК.

## Сборка exe

```bat
build.bat
```

Собирает три варианта:

| что | старт (v25 / v22) | размер | когда брать |
|---|---|---|---|
| `dist\lsk_placer.exe` | 1.0 / 1.3 с | 13 МБ | один файл, «скопировал и запустил» |
| `dist_fast\lsk_placer\lsk_placer.exe` | 0.3 / 0.6 с | 30 МБ (папка) | быстрый старт, ставится папкой |
| `dist\lsk_probe.exe` | — | 10 МБ | диагностика, пишет `probe_report.txt` |

Иконка: положить `icon.ico` в корень проекта (сборка подхватит сама).
Из любой картинки не меньше 256×256:

```bat
python tools\make_icon.py C:\путь\картинка.png
```

Версия в ресурсы exe (`Свойства → Подробно`) берётся из `lsk/__init__.py`
и подставляется скриптом `tools/make_version_info.py` при сборке.

Установленный Python на целевой машине **не нужен** (всё внутри), но разрядность
exe и КОМПАСа должна совпадать (x64). `ksapi.py` и DLL КОМПАСа не пакуются в exe —
они берутся из установленного КОМПАСа при запуске (поэтому инструмент работает с
разными версиями).

Служебные режимы панели: `lsk_placer.exe --probe` (отчёт + открыть в блокноте),
`lsk_placer.exe --selftest` (автотест во временной детали).

## Как инструмент общается с КОМПАСом (важно для v22)

Способ выбирается автоматически:

| версия КОМПАСа | что используется |
|---|---|
| v24 / v25 | `ksapi.py` из каталога `Bin` — C-обёртка над `ksAPICLink.dll` |
| v22 и старше | COM-сервер `KOMPAS.Application.7` + `kAPI7.tlb`, через `comtypes` |

В v22 просто нет `ksapi.py` — Python-обёртку ASCON добавил позже, поэтому там
инструмент работает через COM (API v7, тот же, что описан в SDK v22). Различия,
которые учтены: интерфейсы берутся через `QueryInterface` по typelib, свойства
(`Name`, `X`, `IsPlanar`) обёрнуты в методы, а **удаления объектов в COM-API нет** —
поэтому «отменить» = штатный `Ctrl+Z` в КОМПАСе (создание тройки идёт одним
шагом отмены).

Принудительно выбрать бэкенд можно переменной окружения:
`set LSK_BACKEND=com` (или `ksapi`) — удобно для проверки COM-пути на новой версии.

## Проверено на

| КОМПАС | доступ к API | что проверено |
|---|---|---|
| **v22.0.0** | COM `KOMPAS.Application.7` | диагностика, самотест (создание тройки, координаты), жест, панель |
| **v25.0.5** | `ksapi.py` (C-обёртка) | всё выше + удаление ЛСК из API, сквозной тест `tools/check_e2e.py` |

Отчёты с обеих машин лежат в [docs/COMPAT.md](docs/COMPAT.md).

## Требования

* КОМПАС-3D **v22 и новее**, 64-бит, запущенный;
* Python 64-бит той же разрядности, что КОМПАС (проверено на 3.14);
* в каталоге `Bin` — либо `ksapi.py`/`constants.py` (v24+), либо `kAPI7.tlb` (v22,
  COM-путь); `probe_env.py` показывает, что найдено;
* сторонних библиотек не требуется — только стандартная поставка Python (Tkinter).

## Запуск и проверки

```bash
python probe_env.py        # диагностика: версия КОМПАСа и доступные возможности API
python selftest.py         # автотест: временная деталь, создание/удаление ЛСК
python main.py             # панель управления
```

Диагностики в `tools/` (работают во временных документах, закрывают их без
сохранения, твои модели не трогают):

```bash
python tools/check_overlay.py  # подсказка-стрелка: появление, поворот по всем 6 осям
python tools/check_faces.py    # поиск грани по точке, проекция, нормаль
python tools/check_pick.py     # луч взгляда и выбор объектов (и его странности)
python tools/check_e2e.py      # сквозной сценарий: точка -> курсор -> протяжка -> 3 ЛСК -> Ctrl+Z
python tools/diag_points.py    # какие точки вообще видит API в открытой детали
python tools/live_place.py     # поставить/убрать тройку в точку по номеру, без курсора
```

## Как это устроено

```
main.py            точка входа
lsk/kompas.py      поиск установленного КОМПАСа, импорт ksapi, проверка возможностей API
lsk/model.py       активная деталь: коллекция ЛСК, точки, создание тройки, удаление
lsk/picking.py     проекция точек в пиксели, привязка к точке, выбор оси по протяжке
lsk/geometry.py    векторы, матрицы ЛСК (16 чисел), единицы (мм)
lsk/session.py     сценарий установки (нажатие/отпускание), отмена, журнал
lsk/ui.py          панель Tkinter (имена, отступ, клавиша, журнал)
lsk/config.py      настройки в %APPDATA%\lsk_placer\config.json
lsk/hotkey.py      отслеживание нажатия И отпускания клавиши
lsk/overlay.py     стрелка-подсказка направления (своё прозрачное окно поверх КОМПАСа)
lsk/win32cursor.py позиция курсора в координатах окна
```

Технические детали и подводные камни API — в [docs/API_NOTES.md](docs/API_NOTES.md)
(единицы, матрица ЛСК, особенности `GetPickRay`, группировка отмены).

## Ограничения и планы

* v22 работает, но «удалить тройку» там реализовано через команду отмены
  (`Ctrl+Z`), потому что в COM-API удаления объектов нет. На v25 удаление
  делается напрямую.
* Точку нужно ставить **на поверхность** детали (привязка «на грани»), иначе
  непонятно, куда её положили; для привязки курсора это не мешает.
* Горячая клавиша меняется в панели (`Ctrl+1`, `Ctrl+Alt+L`, `F9`, ...).
Работает она **только когда активно окно КОМПАСа** — в браузере, почте и других
программах ничего не перехватывается. Галочка «Инструмент включён» отключает
перехват полностью (например, если нужно вводить «1» в диалогах КОМПАСа).
Клавишу без `Ctrl`/`Alt` лучше не ставить: пока окно КОМПАСа активно, она
забирается целиком.
* Сборка exe (PyInstaller) — после отладки; учесть разрядность Python.
* Дубли имён не переименовываются: предупреждение и запрос подтверждения.
