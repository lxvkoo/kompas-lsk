# ЛСК → КОМПАС

Утилита для быстрой расстановки локальных систем координат (ЛСК) в деталях
КОМПАС-3D. Наводишь курсор на проставленную точку модели, нажимаешь `Ctrl+Alt+L` —
появляются три ЛСК: базовая, векторная (`_V`, отступ по нормали) и поворота
(`_R`, отступ в плоскости грани).

Работает через официальную Python-обёртку API КОМПАС-3D (`ksapi.py` из каталога
`Bin` установленного КОМПАСа) — без COM, без сторонних библиотек.

## Как это выглядит в работе

1. В детали инструментом «Точка» / «Точка в центре» проставляются точки — там,
   где должны стоять ЛСК.
2. Запускается панель (`python main.py`), выбирается имя (например `ЛСК_Т03`).
3. Курсор наводится на точку в окне модели, нажимается `Ctrl+Alt+L`.
   В модели появляются `ЛСК_Т03`, `ЛСК_Т03_V`, `ЛСК_Т03_R` с включённой надписью.
4. Дальше: выбираешь другое имя (или то же) и повторяешь — сколько нужно.

Направление берётся из геометрии: ось Y базовой ЛСК = нормаль грани, на которой
лежит точка, ось X — проекция глобальной X на плоскость грани, Z = X×Y. Поэтому
ЛСК корректно ставятся на любую плоскость (сверху, сбоку, сзади). Кнопками в
панели выбирается «наружу/внутрь» для `_V` и ось для `_R` (`+X`, `-X`, `+Z`,
`-Z`) — выбор запоминается отдельно для каждого имени.

## Требования

* КОМПАС-3D **v22 и новее**, 64-бит, запущенный;
* Python 64-бит той же разрядности, что КОМПАС (проверено на 3.14);
* в каталоге `Bin` установленного КОМПАСа должны быть `ksapi.py`, `constants.py`,
  `constants3d.py` (есть в v25; наличие в v22 проверяется `probe_env.py`);
* сторонних библиотек не требуется — только стандартная поставка Python (Tkinter).

## Запуск и проверки

```bash
python probe_env.py        # диагностика: версия КОМПАСа и доступные возможности API
python selftest.py         # автотест: временная деталь, создание/удаление ЛСК
python main.py             # панель управления
```

Отдельные диагностики в `tools/` (все работают во временных документах и
закрывают их без сохранения, твои модели не трогают):

```bash
python tools/check_faces.py   # поиск грани по точке, проекция, нормаль
python tools/check_pick.py    # луч взгляда и выбор объектов по лучу
python tools/check_e2e.py     # сквозной сценарий: точка -> курсор -> три ЛСК
python tools/check_click*.py  # эксперименты с перехватом клика (см. docs/API_NOTES.md)
```

## Как это устроено

```
main.py            точка входа
lsk/kompas.py      поиск установленного КОМПАСа, импорт ksapi, проверка возможностей API
lsk/model.py       активная деталь: коллекция ЛСК, точки, создание тройки, удаление
lsk/picking.py     курсор -> луч взгляда -> ближайшая 3D-точка -> нормаль грани
lsk/geometry.py    векторы, матрицы ЛСК (16 чисел), расстояние до луча
lsk/session.py     сценарий установки (горячая клавиша), отмена, журнал
lsk/ui.py          панель Tkinter (имена, направления, отступы, журнал)
lsk/config.py      настройки в %APPDATA%\lsk_placer\config.json
lsk/hotkey.py      глобальная горячая клавиша (RegisterHotKey)
lsk/win32cursor.py позиция курсора в координатах окна
```

Почему по горячей клавише, а не по клику: события мыши КОМПАС в Python не
доставляет (проверено на v25, обработчик не вызывается), см.
[docs/API_NOTES.md](docs/API_NOTES.md). Заодно так быстрее: одно действие вместо
двух. Технические детали API (матрица ЛСК, единицы, координаты пикселей) — там же.

## Ограничения и планы

* Проверено на КОМПАС v25. Для v22 нужно прогнать `probe_env.py` и прислать
  вывод: в коде уже есть запасные пути (ЛСК через `IAuxiliaryGeomContainer` или
  `AddObject`, защита `hasattr`).
* Если точка не лежит на грани (например, центр отверстия «в пустоте»),
  направление берётся по ближайшей грани, и в журнал пишется предупреждение.
  В планах — брать ось из окружности/цилиндра, к которым относится точка.
* Допуск привязки считается с учётом масштаба вида (`snap_tol_px`, по умолчанию
  10 пикселей): в мелком масштабе один пиксель — это миллиметры.
* Горячая клавиша задаётся в `config.json` (`"hotkey": "Ctrl+Alt+L"`), поле в
  панели — в планах.
* Дубли имён не переименовываются: предупреждение и запрос подтверждения.
* Сборка exe (PyInstaller) — после отладки; учесть разрядность Python.
